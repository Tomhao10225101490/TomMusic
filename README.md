# Tom Music 1.4

原生 macOS 音乐播放器，基于 **SwiftUI / AppKit / AVFoundation**。本地音乐、在线发现、公开音频链接解析、完整文件保存及离线播放共用一套资料库。新增默认的 **「直接听歌」**：原生搜索音轨、缓冲独立 AAC，再通过 AVAudioPlayer 和原生播放条播放，**不打开视频、不加载网页播放器**，不需要 Apple Music 或开发者账号。旧网页播放保留为单独的「网页 / MV」选项。

本地播放器和资料库仍为原生实现，不是 Electron。应用没有自建广告、推荐信息流或分析遥测；**来源平台的网页/视频播放器可能含广告、推荐或登录提示**，不删除或遮挡其控件。

**状态说明：这一版已通过下述真实验收，但不满足“全网任意歌曲都能下载”的要求。** BTS《FAKE LOVE》现已实际在 Tom Music 内播放所选公开剪辑来源的**独立 AAC 音轨，约 242 秒，从开头播放到自然结束，零视频轨道**。但没有验证到官方专辑原版的完整保存及离线播放；不能把这份来源标注为剪辑版的音轨冒充已核验原版。

## 打开

双击 **`dist/Tom Music.app`**，或把它拖入「应用程序」。压缩包为 **`dist/Tom Music-1.4.0-macOS-arm64.zip`**，旁有 `.sha256` 校验文件。已解压到项目目录之外，核对所有文件哈希与签名，并独立启动操作验收。

- macOS 14+，当前包为 Apple Silicon / arm64。
- 应用自身不要求服务器、Node.js、账户或订阅；外部官方平台可能要求账户或付费。
- 本地 ad-hoc 签名，**尚未 Apple 公证**；不是已公证的公众发行包。

## 原生直接听歌（1.4 新增，默认入口）

1. 左侧点击 **「全网音乐发现」**，默认进入 **「直接听歌」**。
2. 输入歌名或歌手，点 **「搜索音轨」**，在原生结果列表中选一首并点 **「播放音频」**。
3. 完整独立音轨缓冲好后，用窗口底部**原生播放条**控制播放、暂停、音量与进度。这里没有视频画面、网页或隐藏 MV。
4. 支持输入标准 B站 BV 链接或 BV 编号定位来源；来源链接只在你主动点击时打开。
5. 返回本地资料库时音乐可继续播；选择另一首本地音乐会释放旧音轨缓存，不会同时播放两首。

当前原生曲源来自 B站公开内容的**独立 DASH AAC 音轨**，不是把整个视频下载再隐藏。只选择平台实际返回的音频资源，下载后用 AVFoundation 验证 **音频轨道存在、视频轨道为零、无 DRM、时长与所选来源一致**，再交给 AVAudioPlayer。会先缓冲完整音轨，因此不是逐段实时起播。

已实际验证：

- 用户指定《FAKE LOVE》剪辑来源：**242.302 秒、6,373,337 字节、AAC、48 kHz 双声道、约 209 kb/s、1 个音频轨道 / 0 个视频轨道**。完整自然结束、暂停/恢复、原生进度拖动、取消及本地切换均已通过。
- 另行输入 **「周杰伦 晴天」→ 点击真实原生结果 → 独立音频播放**，无粘贴/硬编码曲目 ID；所选音轨约 4:29，上传者 VV音乐局。没有将上传者宣称的「无损」当作解码事实。
- 原始标题、上传者、翻唱/剪辑/日语/伴奏/AI 等版本提示保留。没有独立核验原唱/母带/所有权；公开可播不等于官方专辑原版。

### 音频缓存、权限与会话

- 单音轨最大 **80 MB**；专属缓存目录最多 **500 MB**。只有音频缓冲，不把签名音频地址或临时曲目写入资料库。
- 正常切换曲目、退出应用会移除自己的 UUID 音频缓存。崩溃残留在下次缓冲时清理超过 24 小时的项目；不会清理用户原文件或受管理音乐目录。**不是永久下载或重启后离线曲库**。
- 搜索/元数据响应上限 2 MB，正常匿名会话只接收平台公开首页返回的 Cookie，存储于独立临时 Cookie jar；不读取浏览器或用户账户 Cookie，不生成指纹/签名，不使用登录凭证。
- 实时检查明确的公开/非付费、非专享、后台和保存标记；未知或受限时不取音轨。多分 P 合集及非第一分 P 当前明确拒绝，不偷偷改播另一分 P。
- 音频只使用同一 API 响应中平台提供的同一音轨 URL，最多尝试两个已发布位置；HTTPS、公开域名、CDN 白名单、字节/超时/重定向上限仍有效，不猜镜像或签名。
- 这里使用平台公开网页 API，**不是官方承诺长期稳定的音乐 SDK**。平台验证、登录、地区或付费限制会导致明确失败；不保证任意歌曲都能获取。权限字段也不是本应用对上传者版权归属的认证。

## 可选网页 / MV（1.3 保留，不是原生听歌模式）

1. 左侧 **「全网音乐发现」→「网页 / MV」**。
2. 选择 B站，输入歌名、艺人，点击 **「搜索 / 打开」**。
3. 在应用内显示的真实平台结果中点选视频；B站视频会打开**同一视频、同一分 P 的官方外链播放器**，声音仍在 Tom Music 内播放，不跳到浏览器。
4. 也可以直接粘贴 B站 HTTPS 视频链接。支持源播放器自身的音量、进度等控件，以及窗口下方的「暂停网页 / 继续网页」。
5. 切出此页会暂停并移除网页播放器；切回本地音乐不会同时播放两个来源。本地进度/下一首命令不会在网页听歌时偷偷换成本地歌。

已完整实测的用户指定曲目：

`https://www.bilibili.com/video/BV1JV62BaEVo/`

来源标题为 **BTS《FAKE LOVE》【剪辑版】**，上传者 **HiRes音源体验**；约 243 秒，**不是已核验的官方专辑原版**，也不验证上传者的「4K / Hi-Res」宣传。已验证不静音播放、暂停/恢复、最小窗口、无跳进度播放到自然结尾及不写入资料库文件。它是实际公开视频，不是生成的演示音频。

另有 YouTube 网页入口；本机环境播放官方 BTS MV 时，平台要求 **Sign in to confirm you're not a bot**，尚未验证整曲成功。不绕过该验证，不把封面、标题或时长加载成功算作播放成功。

### 网页模式边界与隐私

- 只接受 B站 / YouTube 系列平台的 HTTPS 主导航，拒绝账号密码 URL、自定义端口、任意网站、本机或内网链接。Google 账户页面仅供平台正常登录流程。
- 这是可见的来源网页播放器，不抓取媒体地址、不生成下载链接、不代签名、不破解付费或 DRM，也不把视频保存到本地资料库。
- 网页运行平台正常脚本/子资源；主导航白名单**不等于逐个子请求的 DNS 隔离**。原生抓取器的 robots、字节上限、并发及下载限制不适用于平台网页自身的正常加载。
- 使用独立临时 WebKit 会话，不读取 Safari/Chrome 的登录 Cookie，不主动持久化网页登录；关闭此页会丢弃会话。平台及其子资源服务商可以接收搜索词、IP 和正常浏览信息。
- 没有代理换区、伪造登录或修改系统设置。网站有账号/地区/禁嵌限制时保留真实提示。声明 WebKit 浏览器兼容标记并保留 TomMusic 身份，以免平台把系统 WKWebView 误认为过时浏览器。

## 多源音乐发现

点击左侧 **「全网音乐发现」→「多源搜索」**，输入歌名、艺人或专辑并回车。

自动检索五个来源，最多三个来源请求同时进行；展示每个来源的结果数量、耗时或失败原因。单个来源失败不会替换成演示数据。按标题/艺人与关键词匹配度排列跨来源结果；来源筛选保留其原有排序。

- **Apple 目录**：流行音乐等官方商店元数据与来源链接，支持地区选择。**只提供目录，不在本应用播放或保存 Apple 试听**；显示的目录时长不是本应用已获取整曲的证明。
- **Audius**：按实时可用性与流播权限播放公开音轨。展示真实上传者及平台认证标记；标题写着 “Official MV” 不代表已经核验原唱身份。流播不会保存成资料库文件，也不把流播权限视为下载权限。
- **ccMixter**：检索来源明确声明 CC 授权的音乐，保存完整 MP3 后本地播放，记录作者、来源和条款。
- **Wikimedia Commons**：音频文件发现。格式受当前解码器支持、授权声明可识别时可保存；OGG 等未支持格式或需人工核对的记录仅提供文件页。
- **Internet Archive Netlabels**：搜索发行、展开公开完整 MP3。仅接纳可识别的开放授权声明，排除受限、私有文件。

「更多平台 ↗」另有网易云、QQ 音乐、酷狗、B站和 YouTube 的**浏览器官方搜索入口**，不是五个额外的自动下载解析器。这个菜单仍在浏览器打开；「网页 / MV」另行支持 B站 / YouTube 的应用内网页，原生「直接听歌」使用独立音轨。

### 原版与其他版本

标明标题或专辑中明确出现的翻唱、短版、现场版、日语版、Remix 等提示。BTS 的常用中/韩文艺人别名参与匹配；不靠“同名”合并录音，不把平台上传者认证当成版权或原版保证。

用户指定的回归曲目为 **BTS《FAKE LOVE》**：官方目录找到 `防彈少年團` 的原版，目录时长约 **4:02**，也返回现场/日语/混音版。其他来源出现未认证上传者声称 “Official MV” 的记录及 Cover；应用保留上传者信息与提示，测试没有把这些当作 BTS 原版保存。**原版整曲下载仍未通过验收。**

## 解析公开链接、保存到本地

1. 打开 **「全网音乐发现」→「解析公开链接」**。
2. 粘贴公开 HTTPS 网页或直接音频地址，点击「解析链接」。
3. 解析这一页的 `audio` / `source`、OpenGraph 音频、JSON-LD `AudioObject` 和直接音频链接；不执行脚本、不递归抓站。去重后最多展示 30 个链接，并显示格式。
4. 网页公开可见不等于已核验完整歌曲、原唱或使用权限。确认相应权限后，点击 **「保存并播放」**。
5. 保存成功后进入普通本地资料库，可以收藏、加入播放列表和离线播放；不会把未知授权伪造为 CC 声明。

保护与限制：

- 网页最大 2 MB；API/robots 响应也有独立读取上限；单首保存上限 **80 MB**，支持进度及取消。
- HTTPS、域名/DNS 及重定向检查，最多五次重定向；拒绝本机、内网、IP 字面量、含账号密码或非标准端口的链接。
- 网页抓取遵守 robots.txt；无法确认规则时不继续。官方公开 API 按其用途访问，与网页抓取分开。
- 网络检查属于防御性预检，**不是能抵御所有恶意 DNS 重绑定的网络隔离沙箱**。
- 不读取浏览器登录 Cookie，不绕过账号、付费、私有文件或 DRM。受限来源会说明错误或引导至来源页面；不拿试听或另一首歌替代。

## 原有「在线免费音乐」

保留独立的 Internet Archive 开放授权音乐界面：搜索/浏览、发行选择、分页、音轨时长/大小/授权、完整 MP3 下载及取消、已保存歌曲重播。实测发行可用 `Fleurs d'Hiver`，艺人 Fellirium。

这里仍是**下载完整文件后播放**；新发现页的 Audius 才是即时流播。来源授权为上传者声明，不是本应用对其所有权的保证。

## 导入与纯听歌

- `⌘O` 选择音频；`⇧⌘O` 选择文件夹；也可从访达拖入文件或文件夹。
- 支持 MP3、AAC、WAV、AIFF/AIF、CAF、FLAC，以及系统可解码的 M4A/MP4 音频；**ALAC 通过 M4A 容器支持**，不承诺裸 `.alac` 或所有编码参数。
- 不按歌曲名、歌手或年代限制自有文件；没有可解码的完整音频时，也不会编造一份音乐。
- 导入复制文件，绝不修改原始文件；按 SHA-256 去重，读取内嵌标题/艺人/专辑/封面。无标签时显示中性占位，不编造资料。
- 双击播放；支持收藏、播放列表、队列/历史、随机、循环、进度拖动、音量及浅色/深色外观。
- 本地文件和已保存的完整文件可以离线听。远端流播不伪装成可离线文件。

快捷键：`⌘N` 新建播放列表、`⌘,` 设置、`空格` 播放/暂停、`⌘→` 下一首、`⌘←` 上一首。文本编辑和模态输入保留正常空格。注册 macOS 系统媒体命令。

## 数据、隐私、网络恢复

默认资料库：`~/Library/Application Support/TomMusic/`。

- `Media/`：受管理音频副本；`Artwork/`：封面；`Library.json`：曲目、收藏、播放列表、音量和来源信息。
- 移除只删除受管理副本，不删除原文件。退出应用后可复制整个目录备份。
- 1.4 读取 1.0/1.1/1.2/1.3 的资料库；损坏资料库会报错并禁止覆盖。队列和播放位置暂不跨退出恢复。
- 只有主动搜索、解析、播放、保存或打开链接才联网；不上传本地音乐库。搜索词/IP 会被对应来源获知。
- 元数据缓存最长五分钟、内存条目数受限；请求限速及有限次数重试，Apple 目录请求间隔至少 3.2 秒。
- Audius 播放前重查同一音轨权限，使用官方流播路由而非随机内容节点；以小范围 GET 检查响应并在收到头部后停止。播放失败最多自动恢复一次，暂停会取消待恢复任务，不会换歌或无限重试。
- 系统 VPN 若返回 `198.18/15` Fake-IP，先通过固定 Cloudflare DNS-over-HTTPS 地址核验域名的公开 A/AAAA 记录；只发送域名，不发送本地文件或搜索词。**不修改系统代理、DNS、网络或安全设置。**

## 构建和验证

```sh
./scripts/build.sh
open "dist/Tom Music.app"

# 从独立复制的 App 运行基础自测
python3 scripts/verify-release.py

# 实际编码、内嵌封面、Now Playing、现有音频设备路由
python3 scripts/verify-release.py --extended

# 加入真实开放曲源与下载、五源检索、公开网页、流播与恢复测试
python3 scripts/verify-release.py --network --discovery

# 仅打包通过上述测试的相同 App 字节，并独立解压校验
python3 scripts/package-release.py
```

直接使用 `swiftc`，没有第三方包或完整 Xcode 依赖。部分 CLT 的重复 SwiftBridging 定义通过项目内 VFS overlay 兼容，**不修改系统 SDK**。

诊断拒绝默认用户目录，必须使用隔离空目录。解析器/编码/失败注入用明确标识的测试素材；曲源搜索、完整音乐下载、网页解析及正常音频流播使用真实服务。原生测试脚本为 `scripts/verify-ui.py`、`verify-online-ui.py`、`verify-discovery-ui.py`、`verify-native-audio-ui.py`，可选网页为 `verify-web-ui.py`；需要已授予的辅助功能权限，只驱动隔离资料库；运行条件见脚本。
